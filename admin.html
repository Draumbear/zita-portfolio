Connect to GitHub

This dashboard edits your portfolio by committing directly to your GitHub repo, which GitHub Pages then republishes automatically — usually within a minute. You'll need a fine-grained personal access token scoped to just this repository.

  1. Go to github.com/settings/personal-access-tokens/new
  2. Under "Repository access", choose Only select repositories and pick your portfolio repo
  3. Under "Permissions" → "Repository permissions", set Contents to Read and write
  4. Generate the token and paste it below (it's only stored in this browser, never sent anywhere but github.com)
